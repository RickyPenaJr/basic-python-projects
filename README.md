# 🐍 Basic Python Projects

A fun collection of beginner-friendly Python scripts made for learning and practice. These mini projects explore simple logic, file handling, user input, and light automation — all easy to run right from the terminal.

## 📁 Projects Included

| Filename         | Description                                |
|------------------|--------------------------------------------|
| `guess_game.py`  | 🎯 Number guessing game using random module |
| `todo.py`        | ✅ Simple to-do list stored in a text file  |
| `even_odd.py`    | 🔢 Check if a number is even or odd         |
| `chatbot.py`     | 💬 Basic chatbot using string matching      |
| `age_calc.py`    | 📅 Calculate your age from birth year       |

---

## ▶️ How to Run

1. **Clone this repo:**
   ```bash
   git clone https://github.com/yourusername/basic-python-projects.git
   cd mini-python-projects
   ```

2. **Run any file with Python:**
   ```bash
   python guess_game.py
   ```
